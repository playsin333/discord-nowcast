## Что получится

В профиле и в списке участников сервера появляется «Слушает SoundCloud», «Слушает Яндекс Музыка», а для видео «Смотрит YouTube» или «Смотрит Twitch»:

- название трека, под ним исполнитель, а третьей строкой альбом, если он есть (на Twitch — название стрима и канал);
- откуда играет — в заголовке: «Слушает SoundCloud», «Слушает AIMP»; у плееров без своего приложения Discord (VLC, браузер с неизвестным сайтом) — отдельной строкой;
- обложка — та же картинка, что в самом плеере;
- полоска времени трека, если приложение сообщает его длину;
- кнопка **«Слушать на SoundCloud»** (или на Spotify, YouTube…; для Яндекс Музыки и Telegram — «Найти на YouTube»): кто нажмёт, тот найдёт трек.

На паузе или когда ничего не играет, статус убирается сам.

## Установка

1. **[Скачайте `discord-nowcast.exe`](https://github.com/playsin333/discord-nowcast/releases/latest/download/discord-nowcast.exe)** и положите в папку, которую не будете удалять, например `Документы\discord-nowcast`.
2. **Запустите его.** У часов появится ворон, на рабочем столе — ярлык, и дальше программа будет стартовать вместе с Windows. Скачали заново или перенесли в другую папку — для новой копии всё сделается так же.

Всё: один небольшой файл, больше ничего ставить не нужно. Нужны Windows 10 или 11 и Discord на компьютере (не сайт), а в **Настройки → Конфиденциальность активности** включено «Делиться обнаруженной активностью».

Если Windows пишет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: файл скачан из интернета и не подписан.

### Антивирус пишет, что это вирус

Это ложное срабатывание. У файла нет цифровой подписи, а сам он ставит себя в автозагрузку и обновляется с GitHub. Для антивирусной эвристики такой набор выглядит подозрительно, хотя ничего вредного программа не делает: весь код открыт и лежит в папке `src`. Если Защитник Windows пишет «Операция не была успешно завершена, так как файл содержит вирус или потенциально нежелательную программу»:

1. Откройте **Безопасность Windows → Защита от вирусов и угроз → Журнал защиты**, найдите там discord-nowcast и нажмите **Действия → Разрешить на устройстве**.
2. Скачайте exe заново и сохраните в обычную папку. Не запускайте его прямо из браузера или Telegram: так файл попадает во временную папку, а её Защитник проверяет строже.
3. Если всё равно блокирует, добавьте папку с программой в исключения: **Защита от вирусов и угроз → Управление настройками → Исключения → Добавить исключение → Папка**.

Каждую новую версию мы отправляем в Microsoft как ложное срабатывание, обычно через несколько дней Защитник перестаёт на неё ругаться.

### У значка написано «Нет доступа к Discord: админ или антивирус»

Discord запущен, но Windows не даёт программе к нему подключиться. Чаще всего виноват антивирус: Avast и AVG запускают незнакомые программы в «песочнице», откуда к Discord не достучаться. Добавьте discord-nowcast.exe в исключения антивируса (в Avast: **Меню → Настройки → Общее → Исключения → Добавить исключение**) и перезапустите программу.

Вторая причина — Discord запущен от имени администратора: Windows не даёт обычной программе подключиться к программе, запущенной от имени администратора. Так бывает, даже если вы открыли Discord как обычно: в его свойствах может стоять галочка запуска от администратора. Проверить можно в диспетчере задач: вкладка **Подробности** → правой кнопкой по заголовку столбца → **Выбрать столбцы** → **С повышенными правами**. Если у Discord.exe там «Да»:

1. Закройте Discord полностью (правой кнопкой по его значку у часов → **Выйти из Discord**).
2. Правой кнопкой по ярлыку Discord → **Свойства** → **Совместимость**: снимите галочку **Запускать эту программу от имени администратора**. То же самое проверьте у файла `Update.exe` в `%LOCALAPPDATA%\Discord`.
3. Откройте Discord снова.

Если не получается, можно запустить от имени администратора и discord-nowcast: правой кнопкой по exe → **Запуск от имени администратора**.

## Значок у часов

Ворон у часов, в правом нижнем углу экрана, — это управление программой. Его видите только вы, в Discord его не видно никому. Наведите мышку — увидите текущий трек; нажмите — откроется меню:

| Пункт | Что делает |
| --- | --- |
| Скрыть статус на час | убирает статус на час; нажмите ещё раз, чтобы вернуть |
| Источники в статусе | галочка на каждое приложение, которое сейчас играет; снимите, чтобы, например, YouTube из браузера не попадал в статус |
| Что видит Windows | все приложения, которые сейчас сообщают о треке, играющие и на паузе; нажатие копирует ID приложения |
| Запускать вместе с Windows | включено по умолчанию |
| Свой статус… | вместо трека — «Слушает nowcast», «Смотрит nowcast» или «Играет в nowcast» с двумя своими строками (вторая необязательна), картинкой и временем (сколько уже играет, до 100 часов). У «Играет» Discord ставит nowcast под заголовок, и строки идут ниже. Клик по картинке или первой строке в Discord открывает сервер nowcast. Ссылки, реклама казино и 18+ в строках не показываются. Галочка у пункта — свой статус включён |
| Настройки… | окно настроек: что видно в списке участников, откуда брать обложку, кнопка, пауза, источники, автозагрузка, обновления. Изменения применяются сразу |
| Открыть лог | что уходило в Discord и какие были ошибки |
| Скопировать диагностику | копирует всё, что нужно для вопроса в поддержку: версию программы и Windows, что видит Windows, найден ли Discord, настройки и конец лога. Вставьте это в сообщение на форуме помощи. Имя вашей папки пользователя скрывается |
| Проверить обновления | скачивает новую версию и перезапускается; раз в шесть часов программа проверяет и сама |
| Выход | останавливает программу и убирает статус |

## Настройки

Большая часть есть в окне настроек. Все они лежат в `config.json` в `%APPDATA%\discord-nowcast`, который открывается из окна по ссылке «Дополнительно».

| Настройка | Что значит |
| --- | --- |
| `clientId` | приложение Discord, чьё имя стоит после «Слушает». У Яндекс Музыки, Spotify, SoundCloud, YouTube, YouTube Music, Twitch, VK Музыки, Apple Music и Telegram есть свои, у остальных плееров общее. Чтобы всегда было своё имя, создайте приложение на [discord.com/developers/applications](https://discord.com/developers/applications) (**New Application**) и впишите сюда его **Application ID** |
| `inList` | что видно в списке участников после «Слушает»: `source` — откуда играет (по умолчанию; у сервисов со своим приложением Discord строки статуса — трек и исполнитель, источник в заголовке «Слушает SoundCloud»), `artist` — исполнитель, `title` — трек, `app` — имя приложения Discord |
| `showPaused` | `true` — не убирать статус на паузе, а писать «пауза» |
| `coverSource` | откуда обложка (в окне: «Обложка трека»): `player` — из плеера, а если плеер её не отдал или ни один хостинг не принял, из iTunes (по умолчанию); `itunes` — обложка альбома из iTunes, без загрузки на хостинги, а если трека там нет, из плеера (удобно, если хостинги у вас не работают); `none` — без обложки |
| `coverSearch` | `false` — при `player` не искать обложку в iTunes |
| `buttons` | `false` — без кнопки «Слушать на …» |
| `hideAlbum` | `true` — убрать третью строку статуса с названием альбома (в окне: «Убрать альбом») |
| `checkUpdates` | `false` — не проверять обновления самой |
| `image` | ссылка на картинку, которая показывается, если плеер не отдал обложку |
| `own`, `ownType`, `ownTitle`, `ownLine2`, `ownMinutes` | свой статус (в окне «Свой статус»): включён ли, тип (`listening`, `watching`, `playing`), строка 1, строка 2, сколько минут уже играет (до 6000). Картинка лежит рядом, в файле `own-picture` |
| `ownPicture` | только на Linux: путь к картинке своего статуса |
| `hide` | приложения, которые не показывать: `["chrome", "Telegram"]` |
| `names` | свои названия источников: `{"chrome": "YouTube"}` |

## Linux (бета)

Есть версия для Linux: тот же статус, те же приложения Discord у сервисов, обложки, кнопка и «Свой статус». Это бета: проверьте и напишите на [сервере](https://discord.gg/pHzmvghmJR), что работает, а что нет.

**Установка.** Выберите вариант под свой дистрибутив:

- Ubuntu, Debian, Mint, Pop!_OS: [discord-nowcast_amd64.deb](https://github.com/playsin333/discord-nowcast/releases/latest/download/discord-nowcast_amd64.deb), затем `sudo apt install ./discord-nowcast_amd64.deb`;
- Fedora, openSUSE: [discord-nowcast.x86_64.rpm](https://github.com/playsin333/discord-nowcast/releases/latest/download/discord-nowcast.x86_64.rpm), затем `sudo dnf install ./discord-nowcast.x86_64.rpm`;
- любой другой: [AppImage](https://github.com/playsin333/discord-nowcast/releases/latest/download/discord-nowcast-x86_64.AppImage) (сделайте файл исполняемым в его свойствах и запустите) или просто программа одним файлом, [discord-nowcast-linux-amd64](https://github.com/playsin333/discord-nowcast/releases/latest/download/discord-nowcast-linux-amd64).

Для ARM (Raspberry Pi и подобных) в [релизе](https://github.com/playsin333/discord-nowcast/releases/latest) лежат `_arm64.deb`, `.aarch64.rpm` и `discord-nowcast-linux-arm64`.

Запустите discord-nowcast из меню приложений (или файлом). При первом запуске программа добавляет себя в автозапуск, отключить можно в меню значка.

**Как узнаёт трек.** Через MPRIS: это общий для Linux способ, которым плееры сообщают, что играет. Так делают Spotify, браузеры (Firefox, Chrome, Chromium, Brave, Яндекс Браузер), Telegram, VLC, Rhythmbox, Strawberry, Elisa и почти все остальные. Сайт во вкладке браузера узнаётся по адресу страницы или картинки: YouTube, YouTube Music, SoundCloud, Яндекс Музыка, VK, Twitch. Если браузер адрес не сообщает, в статусе будет его имя, тогда помогает `names`.

**Значок в трее.** В KDE, Cinnamon, XFCE, MATE и Budgie ворон появляется сам. В GNOME (Ubuntu, Fedora) значков в трее по умолчанию нет: нужно расширение [AppIndicator](https://extensions.gnome.org/extension/615/appindicator-support/) (в Ubuntu оно уже включено, в Fedora — `sudo dnf install gnome-shell-extension-appindicator`, потом выйти и войти). Без значка программа тоже работает, просто меню не видно. Меню: текущий трек, «Скрыть статус на час», «Свой статус вместо трека», автозапуск, настройки, лог, диагностика, выход.

**Discord из Flatpak и Snap** находится сам, ничего настраивать не нужно. Discord в браузере, как и на Windows, не подходит. Если стоит Vesktop, в нём должна быть включена arRPC (поддержка статусов от программ).

**Настройки** лежат в `~/.config/discord-nowcast/config.json`, ключи те же, что в таблице выше. Окна настроек на Linux нет: пункт меню «Открыть настройки» открывает этот файл, программа подхватывает изменения сразу после сохранения. Для своего статуса картинку задаёт ключ `ownPicture`: путь к любой картинке, например `"~/Картинки/аватар.png"`. Программа сама уменьшит её и загрузит. Лог — `~/.config/discord-nowcast/log.txt`. Пункт «Диагностика» сохраняет и открывает текст для вопроса в поддержку, то же самое печатает `discord-nowcast --diagnostics` в терминале.

**Обновления.** Сама себя программа на Linux не обновляет: когда выходит новая версия, в меню появляется пункт «Вышла версия …». Пакет обновляется так же, как ставился, а AppImage нужно скачать заново.

## Как это работает

Windows сама знает, что играет: это та плашка с треком, которая появляется при нажатии кнопок громкости. discord-nowcast два раза в секунду читает её (системные медиасессии) и, когда что-то меняется, отправляет статус в Discord через его локальный канал, тот же, через который статус ставят игры.

- **Название источника** берётся из идентификатора приложения. Если сайт установлен как приложение (SoundCloud или YouTube Music через «Установить» в Chrome или Edge), берётся его имя из меню «Пуск». В обычной вкладке браузера сайт узнаётся по заголовку окна: там, где он содержит название трека, ищется YouTube, Twitch, SoundCloud и другие. Поэтому в статусе будет SoundCloud, а не Chrome.
- **«Слушает SoundCloud».** Discord пишет после «Слушает» имя приложения, через которое пришёл статус. Поэтому у каждого сервиса своё приложение Discord, и программа переподключается к нужному, когда меняется источник. YouTube и Twitch идут с типом «Смотрит», кроме музыкальных каналов YouTube («Исполнитель - Topic» и VEVO): там «Слушает YouTube».
- **Обложка.** Берётся картинка, которую плеер отдаёт Windows вместе с треком, та же, что в плашке с громкостью, так что в статусе не бывает чужой обложки. Если Windows ещё держит картинку предыдущего трека, программа это замечает и читает её заново. Если плеер кладёт под обложку свой логотип на прозрачной полосе (так делает Spotify), полоса отрезается, и в статусе остаётся одна обложка. Discord показывает картинки только по ссылке из интернета, поэтому она выкладывается на сервер программы (`nowcast-covers.playsin333.workers.dev`, хранит обложку 14 дней, [код](server/worker.js)), а если он не отвечает, на временные хостинги [uguu.se](https://uguu.se) или [litterbox.catbox.moe](https://litterbox.catbox.moe). Если сеть пропала, программа пробует снова, пока трек играет, а ссылку на временном хостинге обновляет, пока он её не удалил. Если плеер картинку не отдал или её не принял ни один хостинг, программа ищет трек в открытом каталоге iTunes: если там есть тот же исполнитель с тем же названием, берётся обложка альбома. Если нет и этого, в статусе иконка приложения Discord. В настройках можно выбрать «Из iTunes»: тогда сначала ищется обложка альбома, а картинка из плеера берётся, только если трека в iTunes нет. Статус нового трека обложку не ждёт: он уходит сразу, а обложка появляется через пару секунд. Чтобы загрузка шла быстро, картинка перед отправкой уменьшается до 300 пикселей и сохраняется как JPEG (если в ней нет прозрачных частей), а если хостинг отвечает медленно, к нему сразу подключается следующий.
- **Кнопка.** Плееры не сообщают Windows ссылку на трек, поэтому «Слушать на …» открывает поиск трека в том же сервисе; для Яндекс Музыки, Telegram и браузеров — поиск на YouTube (со ссылкой на Яндекс Музыку Discord не показывает статус другим). Свою кнопку Discord нажать не даёт, работает она только у других.
- **Частота.** Discord принимает не больше пяти обновлений за 20 секунд, поэтому статус меняется не чаще раза в четыре секунды.

## Ограничения

- Приложение должно сообщать Windows о треке. Почти все так делают; если его нет в «Что видит Windows», программа его тоже не увидит.
- Нужна обычная Windows 10 или 11. В урезанных сборках (Tiny11, Atlas и подобных) часто вырезана часть, через которую плееры сообщают о треке: у громкости нет плашки с треком, а у значка программы написано «Урезанная сборка Windows: нет поддержки медиа». Там трек не видит ни одна программа.
- Яндекс Браузер не сообщает Windows, что играет во вкладке (проверено на ВК Музыке и SoundCloud, флаги браузера не помогают), поэтому программа его не видит. В Edge, Chrome, Firefox и других браузерах всё работает.
- Нужна установленная программа Discord. Discord в браузере не умеет связываться с программами на компьютере.
- Сайт во вкладке браузера узнаётся по заголовку окна, а Windows показывает только заголовок вкладки, которая открыта в окне. Если трек начался в фоновой вкладке, в статусе будет браузер, например Chrome. Тогда переключитесь на вкладку с музыкой, установите сайт как приложение или задайте своё название в `names`.
- Полоска времени есть, только если приложение сообщает длину трека. Яндекс Музыка, Spotify и большинство сайтов сообщают; Telegram нет, у него показывается прошедшее время.

## Приватность

Исполнитель и название трека уходят в Discord (это и есть статус) и в поиск iTunes за обложкой: при «Из плеера» — только когда у плеера своей нет или её не принял хостинг (`"coverSearch": false` отключает), при «Из iTunes» — для каждого трека. Картинка обложки из плеера выкладывается на сервер программы (или uguu.se, litterbox.catbox.moe); сервер хранит только саму картинку, а хеш IP-адреса — час, чтобы ограничить число загрузок. «Без обложки» отключает и то, и другое. Картинка своего статуса выкладывается только на сервер программы и хранится там двое суток (пока статус включён, программа выкладывает её заново) вместе с хешем IP-адреса: если картинка нарушает правила, автор удаляет её, а загрузившему может закрыть доступ. Проверка обновлений спрашивает у GitHub последний релиз. Больше ничего никуда не отправляется.

## Собрать самому

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Используется компилятор C#, который входит в .NET Framework 4.8 на любой Windows 10 и 11, так что ставить ничего не нужно. Код — в папке `src`.

Проверки (строки статуса, кнопка, длинные названия, обложка, время трека) запускаются так:

```
powershell -ExecutionPolicy Bypass -File tests\run.ps1
```

Версия для Linux написана на Go и лежит в папке `linux`. Собирается и проверяется так (тестам нужна шина D-Bus, `dbus-run-session` её даёт):

```
cd linux
go build -o discord-nowcast .
dbus-run-session -- go test ./...
```

На GitHub программа собирается и проверяется сама после каждого изменения.
